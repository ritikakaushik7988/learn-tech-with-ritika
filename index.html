Try a mini lesson

These hands-on demos come from the areas I've worked in: robotics, machine learning and algorithms. Pick one and have a go.

Program a robot

What is this? A coding game. Computers and robots only do exactly what they are told, so you write the instructions.

How to play: Robots follow instructions exactly. Build a program to get the robot to the star without hitting a wall.

    Add some commands, then press Run.

    Teach the computer to guess

    What is this? A simple artificial intelligence (AI). It learns from examples you give it, then makes its own guesses, just like real AI does.

    How to play: Click the board to add examples. The model, called k-nearest neighbours, learns from them and colours every spot by what it predicts. Watch the boundary change as you teach it.

    The same idea powers recommendations and spam filters.

    Watch an algorithm think

    What is this? An algorithm is a set of steps a computer follows to solve a problem. This one, called A*, finds the shortest way from start to finish.

    How to play: Click or drag to draw walls, then press Find path. The A* algorithm searches for the shortest route from the green square to the purple one, the same way map apps and game characters find their way.

    Light purple squares are the ones the algorithm checked.
